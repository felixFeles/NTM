# Revue éditoriale des conflits

Ouvrez `conflict_review.html` dans un navigateur, puis collez le résultat de
`IngestionResult.conflict_report()`. Chaque carte est bloquante : l'éditeur
crée ensuite une source `editorial_decision` qui documente le choix. La
référence publiée affichée sert de priorité, mais l'interface n'applique aucun
arbitrage implicite.
